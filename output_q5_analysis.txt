=== 3. Overflow of i * i ===

  n = 4294967291 (largest 32-bit prime): after i=65535, i*i wraps to 0 <= n, the test stays true,
  and the loop keeps running past sqrt(n); it would only stop when i reaches n (n % n == 0) -> WRONG 'composite'.
  Safe condition i <= n / i: ticket 4294967291 -> prime, divisions = 65534 (sqrt = 65535.99)
